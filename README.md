# SAT Practice Tests Manager

A lightweight web application to create, take, and manage SAT practice tests. This tool helps you save time by recording your answers digitally, keeping track of your scores, and allowing you to mark questions as correct or incorrect.

---

## Features

- **Create new tests** with a name and number of questions.
- **Take tests** using a digital bubble sheet interface.
- **Quick answer input** using keyboard letters (A, B, C, D, E) or buttons.
- **Save answers** and test data to a local JSON file.
- **View saved tests** on the home page with score and date.
- **Mark wrong answers** for detailed review.
- **Dark mode** and **light mode** support.
- Fully responsive UI using **Tailwind CSS**.
- Plain JavaScript, no frameworks required.

---

## To start the application

- make sure Node JS is installed
- run `npm i express`
- run `node server.js` and visit localhost:3000
